# Dunia Warna Kartun 🎨

Game mewarnai berbasis web untuk TK/PAUD, SD, SMP, dan SMA.

## Mainkan

Buka: https://syahpurbachtiar-oss.github.io/mewarnai/

Jika tautan belum aktif, aktifkan **Settings → Pages** pada repositori ini dan pilih branch `main`, folder `/(root)`.

## Fitur

- 4 tingkat kesulitan: TK/PAUD, SD, SMP, dan SMA.
- 12 gambar SVG yang bisa diwarnai, termasuk tema sahabat kembar, putri es, lampu ajaib, fantasi, dan pola mandala.
- Ember cat untuk mewarnai satu area, kuas untuk menggambar bebas, dan penghapus.
- Pilihan warna, warna khusus, serta pengaturan ukuran kuas.
- Undo/redo, reset gambar, zoom/pan untuk level lebih sulit.
- Efek suara opsional, perayaan selesai, dan ekspor hasil ke PNG.
- Tata letak responsif agar lebih nyaman digunakan di komputer, tablet, dan ponsel.

## Cara bermain

1. Pilih tingkat dan gambar dari tombol level di bagian atas.
2. Pilih warna pada palet.
3. Gunakan **Ember** untuk mengisi area, atau **Kuas** untuk menggambar sendiri.
4. Gunakan **Undo**, **Redo**, atau **Hapus** untuk mengoreksi gambar.
5. Pilih **Simpan Karya** untuk mengunduh gambar PNG.

Game berjalan di browser dan tidak memerlukan proses build.
